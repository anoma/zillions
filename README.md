# Zillions Interface

Monorepo for the Zillions Zcash wallet:

- `apps/app` — the Zillions web app
- `apps/keychain` — the Zillions Keychain browser extension
- `packages/zcore` — Rust/wasm wallet core: keys, trial decryption, transparent

Merged from the former `zillions-app`, `zillions-extension`, and `zillions-sdk`
repositories with full git history preserved.
